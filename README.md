# 句间 · 学习助手

无需安装依赖的静态网页应用。使用现代浏览器访问，语音由浏览器 Web Speech API 提供，需要系统安装中文语音。

## 运行

```sh
cd /workspace/yuwen-study
python3 -m http.server 8000 --bind 0.0.0.0
```

打开服务器页面后点击「开始本轮练习」。每轮随机抽取最多 10 道不同题目，句1在左、句2在右，中间用逗号紧凑连接。随机隐藏其中一句，每个字符对应一个下划线。思考时不朗读题目，5 秒倒计时每秒播放一声清亮、有力度且尾音自然衰减的「登～」提示音，每秒一声，共五声，页面提供「试听「登～」提示音（5秒）」按钮。

5 秒后用红色揭晓隐藏句，并按顺序朗读完整两句。朗读完成立即进入下一题，不再额外等待 3 秒。若关闭语音、浏览器不支持语音或朗读失败，会保留完整题目，点击「下一题」继续。语音和倒计时提示音可以分别关闭，支持暂停、继续和结束。题库不足 10 道时练习全部题目。

## 导入

支持 UTF-8 编码文件，最多 5 MB、10000 题。导入成功后替换当前题库，并保存在当前浏览器 localStorage 中。练习过程中不能更换题库。

JSON：`[{"句1":"床前明月光","句2":"疑是地上霜"}]`，也支持 `sentence1`、`sentence2` 字段和两元素数组。

CSV：每行两列，可包含 `句1,句2` 表头；支持引号和引号内的逗号、换行。

TXT：每行一道题，两句以 `|` 或制表符分隔。

页面提供可下载的 JSON 模板。导入内容按纯文本显示。语音支持和中文音色取决于浏览器及操作系统；倒计时阶段只播放提示音，揭晓后才朗读。
